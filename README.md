# Двое — Библия о браке

Мобильное веб-приложение с библейскими текстами об отношениях мужа и жены:
сам текст, объяснение простым языком и конкретные шаги.

## Что внутри

- Выбор роли: жена / муж / вместе — у каждого свой набор текстов
- 53 отрывка с объяснениями
- Три варианта текста: синодальный, современный, простыми словами
- Подробный разбор и раздел «Живые вопросы» у ключевых текстов
- Темы, поиск по разговорным словам, избранное и личные заметки
- Работает без интернета после первого открытия

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | Всё приложение: разметка, стили, тексты, логика |
| `manifest.json` | Настройки установки на главный экран |
| `icon-192.png`, `icon-512.png` | Иконки приложения |
| `vercel.json` | Настройки кэширования (чтобы обновления доходили сразу) |

Сборка не нужна: это статический сайт из одного файла.

## Публикация на Vercel

1. Создайте репозиторий на GitHub и загрузите в него эти файлы (в корень, не в подпапку).
2. На vercel.com: **Add New → Project → Import** ваш репозиторий.
3. Framework Preset: **Other**. Build Command и Output Directory оставьте пустыми.
4. **Deploy**. Через минуту получите адрес вида `https://имя.vercel.app`.

Дальше каждый `git push` в ветку `main` обновляет сайт автоматически.

## Установка на телефон

- **Android:** открыть ссылку в Chrome → меню → «Добавить на главный экран»
- **iPhone:** открыть ссылку в Safari → «Поделиться» → «На экран Домой»

Важно: на iPhone нужно открывать именно ссылку. Присланный HTML-файл iOS
показывает в режиме просмотра с отключённым JavaScript, и кнопки не работают.

## Заметки пользователя

Избранное и заметки хранятся локально в браузере устройства (localStorage)
и никуда не передаются. На разных телефонах — свои записи.

## Тексты и переводы

Синодальный перевод — общественное достояние. «Современный» — редакция
синодального текста на нынешнем русском языке, «Простыми словами» — свободный
пересказ смысла, не перевод. Лицензионные переводы (НРП, РБО и др.) не включены.
